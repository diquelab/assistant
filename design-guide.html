🎯 디자인 개요

Creative Education Foundation의 웹사이트는 교육 기관으로서의 신뢰성과 현대적이고 접근하기 쉬운 인터페이스를 결합한 디자인입니다.

주요 특징

  • 신뢰성: 전문적이고 깔끔한 레이아웃으로 조직의 신뢰성 구축
  • 접근성: 명확한 계층 구조와 직관적인 네비게이션
  • 현대성: 부드러운 그림자, 라운드 코너, 그라데이션 사용
  • 일관성: 전체 페이지에서 일관된 색상, 타이포그래피, 컴포넌트 스타일

브랜드 철학

창의성과 혁신을 지향하는 브랜드로, 생동감 있는 녹색을 주색상으로 사용하여 에너지와 성장을 나타냅니다. 동시에 전문성을 위해 중성적인 회색과 흰색을 보조색으로 사용합니다.

📐 레이아웃 시스템

일관된 레이아웃을 위한 그리드 시스템과 간격 규칙입니다.

그리드 시스템

최대 너비: 1200px
컨테이너 패딩: 40px (데스크톱), 20px (모바일)
요소 간 간격: 20px - 30px (일관된 여백)

레이아웃 패턴

1. Full Width Section with Wave Divider

배경 이미지와 텍스트 오버레이를 포함한 풀 너비 섹션

  • 높이: 300-400px
  • 배경: 검은색 흑백 이미지
  • 텍스트: 흰색, 중앙 정렬
  • 하단 구분선: 녹색 웨이브 또는 선

2. Two Column Layout

콘텐츠와 CTA를 위한 2열 레이아웃

  • 좌측: 텍스트 콘텐츠 (60%)
  • 우측: 녹색 CTA 박스 (40%)
  • 반응형: 모바일에서 스택

3. Four Column Grid

CPSI Conference
CPS for Educators
Professional Development
Workshops
  • 카드 너비: 동일한 4열
  • 간격: 15-20px
  • 배경: #555555
  • 반응형: 2열 또는 스택

4. Two Column Content + Sidebar

메인 콘텐츠와 사이드바 레이아웃

  • 좌측: Events (60%)
  • 우측: News (40%)
  • 수직선 구분자: 연한 회색

🎭 디자인 패턴

반복되는 시각적 패턴과 상호작용 패턴입니다.

섹션 구분 패턴

가로선 구분: 3px 녹색 선 (#7BC43F)
웨이브 구분: 부드러운 곡선으로 섹션 전환
마진: 섹션 상하 30px

호버 상태

  • 버튼: 2px 상향 이동 + 그림자 증가
  • 링크: 색상 변경 + 밑줄 색상 변경
  • 카드: 배경색 변경 (hover 배경)

타이포그래피 패턴

요소 크기 굵기 색상
섹션 제목 (H2) 2em 700 #7BC43F
부제목 (H3) 1.3em 600 #333
본문 1em (16px) 400 #333
라벨/캡션 0.9em 600 #999

간격 규칙

마진 스케일:
- 미니: 5px
- 작음: 10px
- 중간: 15px-20px
- 큼: 30px
- 매우 큼: 40px+

그림자 스타일

가벼운 그림자: 0 2px 8px rgba(0,0,0,0.05)
표준 그림자: 0 4px 16px rgba(0,0,0,0.08)
버튼 호버: 0 4px 12px rgba(123,196,63,0.3)
헤더 그림자: 0 4px 20px rgba(123,196,63,0.2)

모서리 반지름

버튼: 6px
카드: 8px-12px
섹션: 12px
작은 요소: 4px-6px

📱 반응형 설계

모든 화면 크기에서 최적의 경험을 제공합니다.

화면 크기 주요 특징
Desktop
(1200px+)		 풀 너비 레이아웃, 4열 그리드, 2열 콘텐츠
Tablet
(768px - 1199px)		 조정된 패딩, 2열 그리드, 단일 열 콘텐츠
Mobile
(<768px)		 단일 열 레이아웃, 스택 구조, 큰 터치 영역

♿ 접근성 고려사항

  • 색상 대비: WCAG AA 표준 만족 (최소 4.5:1)
  • 텍스트 크기: 최소 14px (본문)
  • 라인 높이: 1.6 (읽기 용이)
  • 포커스 상태: 모든 대화형 요소에 명확한 포커스 표시
  • 대체 텍스트: 모든 이미지에 alt 속성
  • 시맨틱 HTML: 적절한 헤딩 계층 구조
